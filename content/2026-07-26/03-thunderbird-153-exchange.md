Mozilla's free email client Thunderbird shipped version 153, nicknamed
"Meadow," on July 22 — and its headline feature closes a gap that has
sent Exchange users toward add-ons or toward Outlook itself for years:
native support for Microsoft Exchange accounts, built into Thunderbird's
setup flow with no extra software required
([The Thunderbird Blog](https://blog.thunderbird.net/2026/07/thunderbird-153-meadow-is-out-now/);
corroborated by [The Register](https://www.theregister.com/software/2026/07/23/firefox-153-contains-itself-while-thunderbird-153-fixes-almost-everything/5276390)
and [Tux Machines](https://news.tuxmachines.org/n/2026/07/21/Mozilla_Thunderbird_153_Is_Out_with_Various_New_Features_and_Ma.shtml)).
The new Account Hub can now autodiscover an Exchange account, detect its
protocol, and configure the connected calendar and address book
automatically — the kind of setup that used to take a support ticket.
Broader Microsoft Graph integration is already built into the core code,
disabled for now, with full support planned later this year.

The rest of the release is smaller but no less lived-in: Thunderbird
now picks up your operating system's accent color instead of imposing
its own palette, native OS notifications can mark mail read or flag it
as spam without opening the app, and folder sorting and OAuth logins got
a cleanup, alongside what the release notes describe as thousands of
bug fixes.

None of it is flashy, and that's the appeal. Thunderbird's whole case
for existing is that a local, open source, non-subscription email
client can still keep up with what corporate inboxes require — and for
the many people whose employer runs on Exchange, "no longer needing an
add-on to check work email" is a genuine, overdue upgrade.
