Open-weight models keep closing the gap with their closed rivals, and this
week the gap narrowed again in a very public place. On August 6, GitHub
began rolling out Kimi K3 as a selectable model inside GitHub Copilot —
available in VS Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, the
Copilot CLI, the cloud coding agent, github.com, and the Copilot mobile
apps ([GitHub Changelog](https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/)).

Kimi K3 is notable beyond its Copilot debut: at 2.8 trillion parameters, it
is the largest open-weight model released so far, and its weights are
published for anyone to inspect, fine-tune, or run themselves rather than
locked behind an API only its maker controls. Pricing lands well below many
closed frontier models — $3 per million input tokens and $15 per million
output tokens — putting genuinely capable, agentic-coding-grade AI within
reach of smaller teams and individual developers, not just companies with
enterprise contracts ([Kimi](https://www.kimi.com/blog/kimi-k3)).

The rollout is proceeding gradually — GitHub briefly paused it while
resolving an unrelated GitHub Actions incident, then resumed — and it
currently reaches Copilot's Pro, Pro+, Max, Business, and Enterprise plans,
with organization administrators able to enable it for their teams. It's
one more entry in a pattern worth noticing this year: the best available
coding models are increasingly ones anyone can download, read, and modify,
rather than ones only a single company can run.
